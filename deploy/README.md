# Préparation du serveur

Le Dockerfile est un point de départ portable de rendu : `docker build -f deploy/Dockerfile -t remotion-english-video .`. L’image n’a pas été construite ou déployée pendant la préparation locale. Les commandes, volumes, comptes sociaux et horaires définitifs seront établis sur le VPS, conformément à TODO-VPS.md.

L'intégration progressive de l'installation n8n existante est décrite dans [le relevé et les commandes d'exploitation](n8n/OPERATIONS.md). Ce document distingue les accès réellement vérifiés des services et publications encore à raccorder.
