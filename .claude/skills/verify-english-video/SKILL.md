Exécuter npm run check, npm test et npm run verify pour le code/données concernés. Produire le rendu avec scripts/render.cjs puis scripts/verify-video.py. Examiner preview.jpg, les réponses longues, les moments d’entrée/sortie et les gestes du renard. Le corps doit rester fixe ; seule la main salue, le pouce effectue son geste. Distinguer les contrôles automatiques, l’inspection d’images et l’écoute/lecture subjective réellement effectuée. Corriger le périmètre touché avant de conclure ; un succès TypeScript seul ne suffit pas.
